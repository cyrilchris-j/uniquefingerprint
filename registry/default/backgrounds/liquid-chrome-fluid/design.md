# Liquid Chrome Fluid

A viscous metallic fluid background reacting with silky specular turbulence to pointer interaction and ambient time flow.

## Aesthetic DNA
- **Genre**: Technical Luxury / Futuristic Industrial
- **Lighting**: Concentrated specular white highlights falloff into metallic slate and obsidian charcoal.
- **Motion**: Fluid momentum with soft spring lag tracking mouse/touch velocity.
- **Composition**: Multi-layered compositing with contrast boost and desaturated metallic tint.

## Accessibility
- Supports `reducedMotion` prop to settle into a static metallic field without continuous oscillation.
- Low CPU footprint using hardware-accelerated 2D canvas drawing loops.
